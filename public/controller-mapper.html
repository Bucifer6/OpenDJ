Using the mapping in OpenDJ
  1. Click Save mapping. You get a file ending in .opendj-midi.json.
  2. In OpenDJ open Settings → Controllers and select your controller.
  3. Click Import and choose the saved file. The mapping loads automatically every time you plug the controller in.
Close OpenDJ (or any other DJ app) while mapping: on Windows only one program can use a MIDI controller at a time. Needs Google Chrome or Microsoft Edge. Everything stays on this computer; nothing is uploaded.
Contribute this mapping to OpenDJ

Mapped a controller that OpenDJ doesn't support yet? Share it so it works out of the box for everyone. Mappings in the OpenDJ repository are released under CC0 (public domain), so anyone can use and improve them.

This opens a GitHub form in your browser with the mapping already filled in (needs a free GitHub account): check it and click Create. A bot checks the mapping and opens a pull request; it shows as "needs verification" until someone else with the same controller confirms it. A copy of the mapping and a MIDI log are also saved on this computer. Comfortable with git? See mappings/README.md for pull requests.
